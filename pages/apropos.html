À propos du projet

Ce site a été réalisé dans le cadre d'un projet de développement web. L'objectif était de créer un site complet sur un thème de mon choix, en utilisant uniquement HTML, CSS et un peu de JavaScript.

J'ai choisi Cristiano Ronaldo, car sa carrière offre beaucoup de contenu à présenter : des statistiques, des trophées, des records et une histoire marquante.

L'auteur

Skander KDOUS

J'ai réalisé ce projet seul, de A à Z :

  • le choix du thème et l'organisation du site en quatre pages ;
  • la recherche des informations et la rédaction des textes ;
  • la structure HTML de toutes les pages ;
  • la feuille de style CSS ;
  • les scripts JavaScript (carrousel, menu sur téléphone, vérification du formulaire) ;
  • la maquette du site et la gestion du dépôt Git ;
  • le tableau des statistiques et le formulaire de contact.

Comment le site a été fait

  • HTML5 : structure des pages avec des balises sémantiques (header, nav, main, section, article, footer).
  • CSS3 : mise en page avec Flexbox et design responsive grâce aux media queries.
  • JavaScript : carrousel automatique sur l'accueil, menu « burger » sur téléphone et vérification du formulaire de contact.
  • Validation : toutes les pages HTML et la feuille CSS passent le validateur du W3C.
  • Git : le projet est versionné sur GitHub.
  • Police : Poppins, depuis Google Fonts.

À signaler

  • Ce site est un projet scolaire, sans but commercial. Il n'a aucun lien officiel avec Cristiano Ronaldo ni avec ses clubs.
  • Les images appartiennent à leurs auteurs respectifs et sont utilisées uniquement dans un cadre pédagogique.
  • Les statistiques sont à jour en novembre 2026 et peuvent évoluer, car Cristiano Ronaldo joue toujours en club.
  • Le formulaire ci-dessous est vérifié en JavaScript, mais le message n'est pas réellement envoyé : il n'est relié à aucun serveur.
