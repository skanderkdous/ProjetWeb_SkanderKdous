# CR7 - La Légende

Site web consacré à Cristiano Ronaldo : sa carrière, ses statistiques et son palmarès.
Projet de programmation web TI504N, réalisé seul par Skander KDOUS.

## Lien du dépôt
https://github.com/skanderkdous/ProjetWeb_SkanderKdous

## Langages
- HTML5 
- CSS 
- JavaScript 

## Pages
- `index.html` : accueil avec carrousel et tableau des statistiques
- `pages/carriere.html` : parcours club par club
- `pages/palmares.html` : trophées et records
- `pages/apropos.html` : présentation du projet et formulaire de contact

## Fonctionnalités JavaScript
- Carrousel automatique avec flèches et points
- Menu burger sur téléphone
- Vérification du formulaire de contact

`Maquette.pdf` (réalisée sur Figma)

## Lancer le site
Ouvrir `index.html` dans un navigateur.
